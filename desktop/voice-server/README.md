# Atlas Voice reference

`atlas-voice.wav` is the reference clip every Atlas Voice reply is cloned from, and `atlas-voice.txt` is exactly what it says.
It is an ORIGINAL voice, designed from a written list of traits with Qwen3-TTS VoiceDesign in the voice lab
(`tools/voicelab`, results on the `voice-lab-results` branch). It is not a recording of any person.

Current clip: voice lab candidate **A** (`qwen-design-A1`: refined British butler, resonant baritone, dry wit). UTMOS 4.47,
0% word errors. To change Atlas's voice, replace both files with another candidate's clip and its exact words.
